# Dossier de cadrage — copie miroir

Ces documents sont la **référence de travail pour ce dépôt**. Ils sont mis à jour
manuellement depuis `Jarvis/speedfood/` (OneDrive de Malika), qui reste l'endroit
où elle les édite au quotidien avec son assistant personnel.

**Pourquoi une copie ici, et pas juste un lien vers OneDrive ?** N'importe qui qui
clone ce dépôt Git (un autre développeur, un contributeur) doit pouvoir comprendre
le projet sans avoir accès à l'OneDrive de Malika. Un dépôt Git doit être
autosuffisant.

**Si tu modifies un de ces fichiers ici** (pour refléter une décision prise
pendant le développement), pense à reporter le changement dans le fichier
correspondant sous `Jarvis/speedfood/`, sinon les deux copies divergent
silencieusement. À l'inverse, si Malika modifie le cadrage dans Jarvis, il faut
resynchroniser une copie fraîche ici.

## Fichiers

- `TDR.md` — mandat, périmètre, règles métier, critères d'acceptation
- `ADR.md` — décisions d'architecture et questions ouvertes
- `PLAN-EXECUTION.md` — blocs délégables, dépendances, propriété des fichiers
- `AGENT-INSTRUCTIONS.md` — brief commun et règles de sécurité pour toute tâche de code
- `DESIGN-SYSTEM.md` — tokens visuels verrouillés
- `CADRAGE.md` — résumé produit initial
- `FRONTEND-DESIGN-BRIEF.md` — consignes écran par écran (bloc 3/5/6)
- `AUDIT-BLOC-0.md` — état du dépôt au moment de la reprise (bloc 0)
